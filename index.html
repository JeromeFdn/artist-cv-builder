Text Formatting

Use these shortcuts anywhere in the form. They will render correctly in the CV preview and printed output.

Type thisRenders as
*word*italic
**word**bold
***word***bold italic

Example: type *Soft Structures*, Walker Art Center
→ renders as: Soft Structures, Walker Art Center

Note: formatting is shown in the CV preview and print output. It does not appear in the form fields themselves.

Before you print

  1. In the print dialog, look for Headers and footers (Chrome / Edge) or Print headers and footers (Firefox / Safari) and uncheck it. This removes the browser's URL and date lines from your output.
  2. Uncheck Print background graphics (Chrome / Edge) or Print backgrounds (Firefox / Safari) to keep the output clean and save ink.
  3. Set Margins to Default or Normal.
  4. Choose Save as PDF as the destination if you want a PDF file.

Page numbers will be added automatically to the bottom-right of each page.
